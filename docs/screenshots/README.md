# Screenshot placeholders

Add polished screenshots here using these filenames:

- `scan-results.png` — show several extracted candidates in the side panel, ideally a mix of events and tasks.
- `event-review.png` — show the editable Calendar review form with a realistic recurring meeting or schedule.
- `task-review.png` — show a deadline being reviewed for Google Tasks.

Recommended capture guidelines:

- Use a narrow Chrome side-panel crop with the webpage visible enough to communicate context.
- Remove names, account avatars, student IDs, email addresses, course IDs, and private URLs.
- Use realistic public or synthetic examples rather than production account data.
- Keep all screenshots at the same dimensions and export as optimized PNG files.
- After adding them, uncomment the screenshot table in the root README and remove the temporary filename list.
